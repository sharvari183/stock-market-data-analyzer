# 📊 Stock Market Data Analyzer

A Python-based Stock Market Data Analysis project that fetches historical stock data using Yahoo Finance and performs financial analysis including returns, moving averages, volatility, and visualization.

This project is designed for Data Analysis and FinTech portfolio building.

---

## 🚀 Objective

To analyze stock market data and generate insights using Python by:
- Fetching real stock data
- Cleaning and processing data
- Calculating financial indicators
- Visualizing trends and risk
- Exporting results for reporting

---

## 📦 Features

- Fetch stock data using Yahoo Finance
- Data cleaning and preprocessing
- Daily Returns calculation
- Moving Averages (SMA 20 & SMA 50)
- Volatility (risk analysis)
- Data visualization using graphs
- Export dataset to CSV

---

## 🛠️ Tech Stack

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- yfinance
